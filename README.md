# Artificial Intelligence Foundations — CS50 Project 1

Educational AI coursework exploring propositional logic and Minesweeper reasoning. Course-derived material is attributed rather than presented as independent original software.

## Included exercises
- `logic.py` — symbolic logic and model checking
- `minesweeper.py` — knowledge-based game agent
- `puzzle.py` — logic puzzles
- `runner.py` — interactive helper

## Run
See `requirements.txt` for dependencies. Use a local Python environment; some exercises require bundled assets.

## Engineering relevance
Formal reasoning, rule evaluation and testable decision logic.
